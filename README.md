# 🌦️ Weather App — Angular

Frontend da aplicação **Weather**, desenvolvido com **Angular moderno**, utilizando a arquitetura **Standalone Components**, TypeScript e Tailwind CSS.

O projeto consome uma API REST para realizar consultas climáticas, visualizar dados meteorológicos e análises.

---

## 🚀 Tecnologias utilizadas

- 🅰️ **Angular 17**
- 🧩 **Standalone Components**
- 📘 **TypeScript**
- 🎨 **Tailwind CSS**
- 🌐 **Angular Router**
- 🔗 **HttpClient**
- 📊 **Gráficos para visualização dos dados**
- 🐳 Integração com Backend via API REST

---

## 📦 Pré-requisitos

Antes de iniciar, certifique-se de possuir:

- 🟢 Node.js
- 📦 npm
- 🅰️ Angular CLI 17

Verifique as versões instaladas:

```bash
node --version
npm --version
ng version
```

O projeto foi desenvolvido utilizando **Angular 17**.

---

## 📥 Clonando o projeto

Clone o repositório:

```bash
git clone https://github.com/sergiohscl/weather-ui.git
```

Entre no diretório:

```bash
cd weather
```

---

## 📚 Instalando as dependências

Instale as dependências do projeto:

```bash
npm install
```

Caso seja necessário instalar o Angular CLI 17 globalmente:

```bash
npm install -g @angular/cli@17
```

Verifique a versão:

```bash
ng version
```

A versão principal do Angular deve ser:

```text
Angular 17
```

---

## ▶️ Executando o projeto

Para iniciar o servidor de desenvolvimento:

```bash
ng serve
```

Ou:

```bash
npm start
```

Depois acesse:

```text
http://localhost:4200
```

# 🅰️ Angular moderno e Standalone Components

Este projeto utiliza a arquitetura **Standalone**, seguindo a abordagem moderna do Angular.

A partir das versões mais recentes do Angular, não é mais necessário estruturar toda a aplicação utilizando `NgModule` como era comum em versões antigas.

---

As dependências utilizadas pelo componente são declaradas diretamente no próprio componente.

Isso torna a aplicação mais:

- 🧩 Modular
- 🧹 Organizada
- 📦 Fácil de manter
- ♻️ Reutilizável
- ⚡ Otimizada
- 🚀 Alinhada com o Angular moderno

---

O projeto também pode utilizar **Lazy Loading** para carregar funcionalidades somente quando forem necessárias.

---

# 🎨 Tailwind CSS

O projeto utiliza **Tailwind CSS** para construção da interface.

A utilização de classes utilitárias permite construir a interface diretamente nos templates Angular.

# 📌 Versão do Angular

Este projeto utiliza:

```text
Angular 17
```

A escolha do **Angular 17** permite utilizar a arquitetura moderna do framework, incluindo:

- 🧩 Standalone Components
- 🚀 `bootstrapApplication`
- ⚙️ `app.config.ts`
- 🛣️ `app.routes.ts`
- 💉 `inject()`
- 📦 Lazy Loading
- 🧱 Componentes independentes
- 🧹 Menor dependência de `NgModule`

> O projeto não utiliza a arquitetura antiga baseada em `AppModule` como estrutura principal.
